#### <span id="let"></span>Let

</div>

</div>

</div>

  
<span class="strong">**Syntax:**</span>

``` screen
    Let Variable = data
```

  
<span class="strong">**Explanation:**</span>  
If you prefer, you can add `Let` to the start of a
<a href="setting_variables" class="link" title="Setting Variables">variable assignment</a>.
  It will not alter the execution of the program, but is included for
those who are used to including it in other BASIC dialects.  
  

<span class="strong">**Example:**</span>

``` programlisting
    Let Chipmunk = 46    'Identical to: Chipmunk = 46
```
