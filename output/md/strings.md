### <span id="strings"></span>Strings

</div>

</div>

</div>

A fixed‑length string is declared as:

``` screen
    Dim Name * 16
```

This allocates a 16‑byte string (plus one extra byte internally). Fixed
strings are not null‑terminated and do not resize automatically.
