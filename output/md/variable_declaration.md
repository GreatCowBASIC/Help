##### <span id="variable_declaration"></span>Variable Declaration

</div>

</div>

</div>

`Dim` can declare one or more variables on a single line. When multiple
variables are declared together, the type at the end of the line applies
to all variables:

``` programlisting
    Dim A, B, C As Word = 100
```

If no type is specified, the variable defaults to `Byte`.
