=== #script

(((Compiler Directives,#script)))


*Syntax:*
[subs="specialcharacters,quotes"]
----
    #script
    [__scriptcommand1__]
    [__scriptcommand2__]
     ...
    [__scriptcommandn__]
    #endscript
----
*Explanation:*

The `#script` block is used to create small sections of code which GCBASIC runs during compilation.
A detailed explanation and example are included in the <<_scripts,Scripts>> article.
