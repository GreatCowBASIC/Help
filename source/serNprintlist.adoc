==== SerNPrintList

(((Serial Communications,SerNPrintList)))


*Ser1PrintList, Ser2PrintList, Ser3PrintList*

*Syntax:*
[subs="specialcharacters,quotes"]
----
    Ser1PrintList value1, value2 [, value3 ... ]
    Ser2PrintList value1, value2 [, value3 ... ]
    Ser3PrintList value1, value2 [, value3 ... ]
----
*Command Availability:*

Available anywhere the matching <<_sernprint,SerNPrint>> command
(`Ser1Print`, `Ser2Print` or `Ser3Print`) is available.

*Explanation:*

This command sends two or more values, in the order given, using the
channel referred to as Ser1.., Ser2.., Ser3.. according to the rules set by
the related defines -- instead of writing one `SerNPrint` call per value.
Each value can be a string, integer, long, word or byte, and each is sent
using the matching typed `SerNPrint` call for that channel, so mixing types
in one statement works exactly as if each value had been sent with its own
`SerNPrint` statement.

The list may also be written in brackets, as a sub call may be:
`Ser1PrintList ("Count: ", xx, "\r\n")` is the same as
`Ser1PrintList "Count: ", xx, "\r\n"`. The brackets are taken off only when they
hold the whole list, so `Ser1PrintList (a + 1) * 2, b` sends two values.

For a new line, end the list with a string holding a carriage return and a line
feed, written with the `\r` and `\n` escape sequences, as above (see <<_dim,Dim>>
for the string escape sequences). A number in the list is sent as its digits:
`13, 10` sends the four characters `1310`, not a carriage return and a line feed.

*Example:*
[source,gcbasic]
----
    'This program will send a heading, a label and an incrementing value
    'using PORTB.1

    ; ----- Configuration
    #chip 16F886, 16
    #option Explicit

    ; ----- Include library
    #include <SoftSerial.h>

    ; ----- Config Serial UART :
    #define SER1_BAUD 115200   ; baudrate must be defined
    ; Config I/O ports for transmitting:
    #define SER1_TXPORT PORTB  ; I/O port (without .bit) must be defined
    #define SER1_TXPIN 1       ; portbit  must be defined

    ; ----- Variables
    Dim xx As Word
    xx = 1000

    ; ----- Main body of program commences here.
    Do Forever
      Wait 1 s       'time to enjoy the result
      Ser1PrintList "Software-UART: ", xx, "\r\n"   ' <<< the Ser1PrintList instruction
      xx += 1
    Loop
----
*Key line:* `Ser1PrintList "Software-UART: ", xx, "\r\n"` -- sends the label
string, the current value of `xx`, and a carriage return and line feed, all in
one statement.

Exposed in SoftSerial.h authored by Frank Steinberg
