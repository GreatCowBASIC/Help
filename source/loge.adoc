==== Loge

(((Maths,Loge)))


*Syntax:*
[subs="specialcharacters,quotes"]
----
    returned_word_variable = Loge ( __word_value__ )
----
*Command Availability:*

Available on all microcontrollers.

*Explanation:*

The `Loge` command returns the base-e (natural) logarithm, to 2 decimal places.

The values returned are fixed-point numbers, with two decimal places assumed on the right -- or, if you prefer, think of the values as being scaled up by 100.

*Example:*
[source,gcbasic]
----
    dim log_value as word
    log_value = loge ( 10 )          ' <<< the Loge instruction -- returns 230, equating to 2.30
----
*Key line:* `loge ( 10 )` -- returns the natural logarithm of 10 as a fixed-point word, `230`, representing 2.30.
