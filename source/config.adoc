=== #config

(((Compiler Directives,#config)))


*Syntax:*
[subs="specialcharacters,quotes"]
----
    #config __option1__, __option2__, ... , __optionN__
----
*Explanation:*

The `#config` directive is used to specify configuration options for the chip. There is a detailed explanation of `#config` in the <<_configuration,Configuration>> section of the help.

**See Also:**

* <<_configuration,Configuration>> -- the full explanation of PIC CONFIG words, AVR fuses, and GCBASIC's automatic defaults
* <<__chip,#chip>> -- selecting the target chip and clock frequency
