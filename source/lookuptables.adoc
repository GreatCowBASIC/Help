[[overview]]
==== Overview

A *lookup table* stores a list of values accessed via `ReadTable`.

===== Key Features

- Efficient memory usage
- Supports `byte`, `word`, `long`, `integer`
- ASCII strings and inline calculations supported
- External data sources allowed  
_Note: Decimal values are not supported_

[[defining-tables]]
==== Defining Tables

[[single-values]]
===== Single Values

[source]
----
Table TestDataSource
    12
    24
    36
    48
    60
    72
End Table
----

[[multiple-values]]
===== Multiple Values

[source]
----
Table TestDataSource
    12, 24, 36
    48, 60, 72
End Table
----

[[constants]]
===== Constants & Calculations

[source]
----
#define calculation_constant 2

Table TestDataSource
    1 * calculation_constant
    2 * calculation_constant
    3 * calculation_constant
    8 * calculation_constant
    4 * calculation_constant
    5 * calculation_constant
End Table
----

[[strings]]
==== String Tables

[[simple-strings]]
===== Simple Examples

[source]
----
Table Test_1
    "ABCDEFGHIJ"
End Table
----

[source]
----
Table MnuTxt_1
    "  Display_1    Display_2    Display_3  "
End Table

Table MnuTxt_2
    "1: Display"
    "2: System Setup"
    "3: Config 1"
    "4: Config 2"
    "5: Data Log"
    "6: Diagnostic"
    "7: Help+"
End Table
----

[[string-formatting]]
===== Equivalent Representations

- `"String1", "String2", "String3"`
- `"String1String2String3"`
- `"String1"`  
  `"String2"`  
  `"String3"`

[[escapes]]
==== ASCII Escape Sequences

[cols="1,3", options="header"]
|===
| Escape | Meaning
| \a     | Beep
| \b     | Backspace
| \f     | Formfeed
| \n or \l | Newline
| \r     | Carriage Return
| \t     | Tab
| \0     | Null value (ASCII 0)
| \&nnn  | ASCII character in decimal
| \\     | Backslash
| \"     | Double quote
| \'     | Single quote
|===

[[reading]]
==== Reading Lookup Tables

[[basic-reading]]
===== Basic Reading

[source]
----
Dim TableCounter, Invalue as byte

CLS
For TableCounter = 1 to 6
  ReadTable TestDataSource, TableCounter, Invalue
  Print InValue
  Print ","
Next
----

[[length-reading]]
===== Reading Table Length

[source]
----
Dim lengthoftable as word
ReadTable TestDataSource, 0, lengthoftable
Print lengthoftable
----

[[eeprom]]
==== EEPROM Table Storage

[source]
----
#chip 16F628

TableLoc = 2
ReadTable TestDataSource, TableLoc, SomeVar

EPWrite 1, 45  'Optional write

Table TestDataSource Store Data
    12
    24
    36
    48
    60
    72
End Table
----

[[eeprom-limitations]]
===== EEPROM Limitations

- Only `BYTE` values are supported
- `WORD`, `INTEGER`, or `LONG` cannot be stored in EEPROM
