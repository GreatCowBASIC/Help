=== Lookup Tables

[[overview]]
**Overview**

_A lookup table is a list of values stored in the microcontroller’s memory and accessed using `ReadTable`._

__Key Features__

- Efficient memory usage
- Supports `byte`, `word`, `long`, and `integer` types
- ASCII string definitions supported
- Constants and inline calculations permitted
- External data sources allowed  

_Note: Decimal values are not supported_

[[defining-tables]]
**Defining Tables**

[[single-values]]
__Single Values__

[source]
----
Table TestDataSource
    12
    24
    36
    48
    60
    72
End Table
----

[[multiple-values]]
__Multiple Values__

[source]
----
Table TestDataSource
    12, 24, 36
    48, 60, 72
End Table
----

[[constants]]
__Constants & Calculations__

[source]
----
#define calculation_constant 2

Table TestDataSource
    1 * calculation_constant
    2 * calculation_constant
    3 * calculation_constant
    8 * calculation_constant
    4 * calculation_constant
    5 * calculation_constant
End Table
----

**String Tables**

[[simple-strings]]
__Simple Examples__

[source]
----
Table Test_1

----

----

__Equivalent Representations__

- `"String1", "String2", "String3"`
- `"String1String2String3"`

  `"String2"`  
  `"String3"`

|===

| \n or \l | Newline

| \t     | Tab

| \\     | Backslash
| \"     | Double quote
| \'     | Single quote
|===

[[reading]]
**Reading Lookup Tables**

[[basic-reading]]
__Basic Reading__

[source]
----
Dim TableCounter, Invalue as byte

CLS
For TableCounter = 1 to 6
  ReadTable TestDataSource, TableCounter, Invalue
  Print InValue
  Print ","
Next
----

[[length-reading]]
__Reading Table Length__

[source]
----
Dim lengthoftable as word
ReadTable TestDataSource, 0, lengthoftable
Print lengthoftable
----

[[eeprom]]
**EEPROM Table Storage**

[source]
----
#chip 16F628

TableLoc = 2
ReadTable TestDataSource, TableLoc, SomeVar

EPWrite 1, 45  'Optional write

Table TestDataSource Store Data
    12
    24
    36
    48
    60
    72
End Table
----

[[eeprom-limitations]]
__EEPROM Limitations__

- Only `BYTE` values are supported
- `WORD`, `INTEGER`, or `LONG` are not compatible with EEPROM tables
