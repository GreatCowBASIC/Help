=== Referencing

(((Syntax,Referencing)))


This is an advanced subject. Please see <<_variable_types,Variable Types>> for a more general introduction to variables.

*About referencing variables and SFRs*

A variable or SFR (Special Function Register) is a memory location on the microcontroller. Both are referenced the same way in GCBASIC code - by name - but they store different kinds of information: a variable holds a numeric value your program assigns and uses, while an SFR reflects or controls the state of a hardware peripheral (a port, a timer, an ADC, and so on).

[cols=3, options="header,autowidth",width="80%"]
|===
|*Type*
|*Range*
|*Comment*

|Variable
|A byte of 0 to 255 (or wider, for Word/Integer/Long)
|A memory location your program dimensions and assigns

|SFR
|A byte of 0 to 255
|Reflects or controls the state of ports, timers, and other hardware, e.g. `PORTB`, `TRISA`, `ADCON0`

|===

Because GCBASIC treats SFRs as ordinary byte variables, everything that applies to referencing a variable - reading it, writing it, addressing an individual bit with `.n`, or aliasing it - applies equally to referencing an SFR. See <<_variable_memory_allocation_addressing_control,Variable Memory Allocation, Addressing \& Control>> for the full detail on the `@` address-of prefix, `AT` allocation, and `Alias`.

*Referencing an individual bit*

A single bit of a variable or SFR is referenced using dot notation - `name.n`, where `n` is the bit number, counting from 0 for the least significant bit.

[source,gcbasic]
----
    Dir PORTB.0 Out          ' <<< referencing a single bit of an SFR by name and bit number
    Set PORTB.0 On
----
*Key line:* `Dir PORTB.0 Out` -- references bit 0 of the `PORTB` SFR directly, without needing to read, mask, and write back the whole register; GCBASIC compiles this into the correct single-bit instruction for the target microcontroller.

*Referencing by alias*

An alias is an alternative name for an existing variable or SFR, rather than a separate storage location. Referencing an alias reads or writes the exact same memory as referencing the variable it is aliased to.

[source,gcbasic]
----
    Dim MyADResult As Word Alias ADRESH, ADRESL
----

Here, referencing `MyADResult` reads or writes the same two SFR bytes as referencing `ADRESH` and `ADRESL` directly - see <<_variable_memory_allocation_addressing_control,Variable Memory Allocation, Addressing \& Control>> for further worked examples.
