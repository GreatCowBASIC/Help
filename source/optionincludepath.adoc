=== #Option IncludePath

(((Compiler Options,#Option IncludePath)))


*Syntax:*
[subs="specialcharacters,quotes"]
----
    #option IncludePath "__folder__;__folder__;..."
----

*Explanation:*

`#option IncludePath` gives the folders that GCBASIC searches for `#include <...>` files *before* its own
include folder (`..\GCBASIC\include`). A project can then keep its own libraries in a folder of its own and
still include them with `<` and `>`, the same way as GCBASIC's libraries, without copying them into GCBASIC's
include folder.

* The folders are separated by `;`. A folder can be relative to the program's folder, or a full path.
* The folders are searched in the order given; the first one that has the file is used. When none of them
  has it, GCBASIC's include folder is used, as without the option.
* The option applies to every `#include <...>` after it: in the program, and in every file the program
  includes. So a library in a project folder can include another library of the project with `<...>`.
  Put the option before the first `#include` that needs it.
* `#insert <...>` uses the same search.
* `#include "..."` (quotation marks) is not changed: the file is read from the program's folder.
* The option is read from the main program only (not from an include file).
* Without the option, `#include <...>` reads only GCBASIC's include folder, as in earlier builds.

*Example:*

The program `BOOTLOADER_GCB.gcb` with its libraries in the folder `libraries` next to it:

[source,gcbasic]
----
    #chip 18F46J50, 48
    #option IncludePath "libraries"

    #include <usb_msd_polled.h>       // libraries\usb_msd_polled.h
    #include <sd_card.h>              // libraries\sd_card.h
    #include <glcd.h>                 // GCBASIC's own include folder
----

`usb_msd_polled.h` itself has `#include <usb_debug.h>`: that is found in `libraries` too.

Two folders, the first one searched first:

[source,gcbasic]
----
    #option IncludePath "libraries;..\SharedLibraries"
----

*Errors and warnings:*

* A file found in none of the folders gives the error `Cannot find ...`, followed by the folders that were
  searched, for example
  `Cannot find C:\GCstudio\gcbasic\include\not_there.h (searched: C:\Project\libraries; C:\GCstudio\gcbasic\include)`.
* A folder in the option that does not exist gives the warning
  `#option IncludePath: folder not found: ...`; the other folders are still searched.

This option was added in build 1661.
