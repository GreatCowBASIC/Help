==== LCDHome

(((Liquid Crystal Display,LCDHome)))


*Syntax:*
[source,gcbasic]
----
    LCDHome
----
*Command Availability:*

Available on all microcontrollers.

*Explanation:*

The `LCDHome` command will return the cursor to home position.

The currentcontents of the LCD screen will be retained.


*Example:*
[source,gcbasic]
----
    ;Chip Settings
    #chip 16F88,8

    ;Defines (Constants)
    #define LCD_IO 4
    #define LCD_WIDTH 20                ;specified lcd width for clarity only.  20 is the default width
    #define LCD_RS PORTA.6
    #define LCD_NO_RW
    #define LCD_Enable PORTA.7
    #define LCD_DB4 PORTB.4
    #define LCD_DB5 PORTB.5
    #define LCD_DB6 PORTB.6
    #define LCD_DB7 PORTB.7

    Locate 0,0
    Print "Reset"
    wait 1 s
    ClS

    Cursor_Home_Tests:

    cls
    lcdcursor flash
    print "Test Home Cmd"
    LCDHome          ' <<< the LCDHome instruction
    wait 3 s
----
*Key line:* `LCDHome` -- moves the cursor back to row 0, column 0 without clearing the display, so the text already printed by `print "Test Home Cmd"` remains visible.

**See Also:**

* <<_cls,CLS>> -- clears the display and also returns the cursor to home
* <<_locate,Locate>> -- moving the cursor to any specific position, not just home
* <<_lcd_overview,LCD Overview>> -- category overview
